# 🕒 Proofa - Профессиональный трекер времени

Proofa — это профессиональное приложение для отслеживания времени с на базе проекта Kimai с открытым исходным кодом. Система предназначена как для фрилансеров, так и для компаний с десятками или сотнями пользователей.

## ✨ Основные возможности

- **Отслеживание времени**: Мульти-таймер, режим входа/выхода, детальная аналитика
- **Управление проектами**: Клиенты, проекты, активности с бюджетами и тарифами  
- **Выставление счетов**: Автоматическое формирование инвойсов на основе отработанного времени
- **Командная работа**: Роли, права доступа, команды с различными уровнями доступа
- **Отчетность**: Расширенная аналитика, экспорт данных, настраиваемые отчеты
- **API**: JSON REST API для интеграций и мобильных приложений
- **Многоязычность**: Поддержка 30+ языков, включая русский

## 🚀 Быстрый старт для разработки

### Первоначальная установка

```bash
# Автоматическая настройка среды разработки
./setup-dev.sh
```

Скрипт автоматически настроит Docker, установит зависимости, создаст базу данных и запустит все сервисы.

### Ежедневная работа

```bash
# Запуск всех сервисов
./start.sh

# Остановка сервисов  
./stop.sh

# Проверка статуса
./status.sh

# Полная очистка (при проблемах)
./reset.sh
```

### Доступные сервисы

| Сервис | URL | Описание |
|--------|-----|----------|
| 🌐 **Kimai** | http://localhost:8083 | Основное приложение |
| 📧 **MailHog** | http://localhost:8025 | Тестирование email |
| 🗄️ **phpMyAdmin** | http://localhost:8082 | Управление БД |
| ⚡ **Webpack** | http://localhost:8081 | Frontend разработка |

**Данные для входа**: `admin` / `admin`

## 🎯 Генерация тестовых данных

Система автоматически создает реалистичные данные для российской IT-компании:

### Быстрая генерация

```bash
# Полная генерация данных с нуля
docker exec kimai-dev-php php scripts/load_fixtures_manually.php

# Добавление данных к существующим пользователям  
docker exec kimai-dev-php php scripts/generate_new_data.php
```

### Что будет создано

- **35 пользователей** с русскими ФИО и реалистичными email
- **8 клиентов** (российские компании с адресами)
- **37 проектов** с детальными описаниями
- **320+ активностей** с конкретными задачами
- **3 команды** с распределением участников
- **4,600+ записей времени** за последние 3 месяца
- **28+ счетов** с русскими банковскими реквизитами
- **30 профессиональных тегов** с привязкой к задачам

### Проверка результатов

```bash
# Быстрая проверка данных
docker exec kimai-dev-mysql mysql -u kimai -pkimai kimai -e "
SELECT 'Пользователи' as entity, COUNT(*) as count FROM kimai2_users
UNION ALL SELECT 'Проекты', COUNT(*) FROM kimai2_projects  
UNION ALL SELECT 'Записи времени', COUNT(*) FROM kimai2_timesheet
UNION ALL SELECT 'Счета', COUNT(*) FROM kimai2_invoices;"

# Проверка доступности системы
curl -I http://localhost:8083/
```
